# detectAI
Проект по "Структуры и алгоритмы интеллектуальной обработки данных". Счетчик/журнал объектов

**Тема проекта:**  
Разработка WEB приложения учета людей и машин в системах дорожных камер с использованием нейросетевой модели. Ведение журнала обнаруженных объектов.

**Начальный план работы**  
1) Ознакомится с возможностями нейросетей по обнаружению объектов в кадре;
2) Сформировать первичные классы-маркеры для нейросети;
3) Написать первичную логику работы приложения;
4) Доработать интерфейс клиентской части программы.
